    Flash Card App: Setup Steps

    Recreates this project from an empty folder. Requires Node 18+ and npm.

    Part 1: Hello World React project

    A1. Create the project

    npm create vite@latest hello-world -- --template react
cd hello-world
npm install

    Pick react if the template prompt appears. This creates a Vite project with React and the default starter files.

    A2. Replace the starter with Hello World

    Replace the contents of src/App.jsx with:

    export default function App() {
  return <h1>Hello, World!</h1>;
}

    Delete src/App.css and the import './App.css' line if you don't need them.

    A3. Run it

    npm run dev

    Open http://localhost:5173 and you should see "Hello, World!". Stop the server with Ctrl+C.

    Part 2: Flash card app

    1. Create the folder and initialize git

    mkdir flashCard && cd flashCard
git init

    2. Get the source code in the terminal

    Connect the folder to the GitHub repo and pull the app files, including .gitignore, package.json, vite.config.js, index.html and src/:

    git remote add origin https://github.com/sourabhrustagi/flashCardReact.git
git pull origin main

    3. Install dependencies in the terminal

    Install the runtime dependencies, then the dev dependencies, with the pinned versions:

    npm install react@18.3.1 react-dom@18.3.1
npm install -D vite@5.4.11 @vitejs/plugin-react@4.3.4

    Or run npm install to install everything already listed in package.json.

    4. Run the app

    npm run dev

    Or run ./run.sh, which installs dependencies on first run and then starts the dev server. Open the URL Vite prints, usually http://localhost:5173.

    5. Build for production

    npm run build

    Output goes to dist/. Preview it with npm run preview.

    6. Create a React project from scratch

    This project uses Vite, a fast dev server and bundler. Create one with the official template:

    npm create vite@latest flash-card -- --template react
cd flash-card
npm install
npm run dev

    Vite scaffolds index.html, vite.config.js, package.json and a starter src/. This repo replaces the starter files with the app code, and pins versions in package.json.

    To build the same project from the terminal without the template, follow steps 1 to 5 above.

    7. Project architecture

    The app is a small component tree with state kept in one place. Data flows down through props, and events flow up through callbacks.

    flashCard/
├── index.html              Page shell with the #root element
├── vite.config.js          Vite setup with the React plugin
├── package.json            Scripts and pinned dependencies
├── run.sh                  Installs (if needed) and starts the dev server
├── steps.html              This page
└── src/
    ├── main.tsx            Mounts <App /> into #root
    ├── App.tsx             Page layout: wires the hook to the components
    ├── index.css           Global styles and theme tokens
    ├── types/
    │   └── card.ts         The Card type
    ├── data/
    │   └── cards.ts        The list of cards
    ├── hooks/
    │   ├── flashcardsReducer.ts Pure state transitions (next, previous, flip)
    │   └── useFlashcards.ts    Connects the reducer to components
    └── components/
        ├── FlashCard.tsx   Presents one card; calls onFlip when clicked
        ├── ProgressBar.tsx Shows "Card X of Y" and a fill bar
        └── Controls.tsx    Previous, Flip and Next buttons

    src/App.jsx: holds state and the navigation

    import { useState } from 'react';
import { cards } from './cards.js';
import FlashCard from './components/FlashCard.jsx';
import ProgressBar from './components/ProgressBar.jsx';

export default function App() {
  const [index, setIndex] = useState(0);
  const [flipped, setFlipped] = useState(false);

  const total = cards.length;
  const isFirst = index === 0;
  const isLast = index === total - 1;

  // Moving to another card always shows its question side first.
  const goTo = (next) => {
    setIndex(next);
    setFlipped(false);
  };

  return (
    <main className="app">
      <h1>Flash Cards</h1>

      <ProgressBar current={index + 1} total={total} />

      <FlashCard
        card={cards[index]}
        flipped={flipped}
        onFlip={() => setFlipped((f) => !f)}
      />

      <nav className="controls">
        <button onClick={() => goTo(index - 1)} disabled={isFirst}>
          Previous
        </button>
        <button onClick={() => setFlipped((f) => !f)}>
          {flipped ? 'Show question' : 'Flip'}
        </button>
        <button onClick={() => goTo(index + 1)} disabled={isLast}>
          Next
        </button>
      </nav>
    </main>
  );
}

    src/components/FlashCard.jsx: one card that flips on click

    export default function FlashCard({ card, flipped, onFlip }) {
  return (
    <button
      type="button"
      className={`flash-card ${flipped ? 'is-flipped' : ''}`}
      onClick={onFlip}
      aria-label={flipped ? 'Showing answer, click to show question' : 'Showing question, click to reveal answer'}
    >
      <div className="flash-card-inner">
        <div className="flash-card-face flash-card-front">
          <span className="flash-card-label">Question</span>
          <p>{card.question}</p>
        </div>
        <div className="flash-card-face flash-card-back">
          <span className="flash-card-label">Answer</span>
          <p>{card.answer}</p>
        </div>
      </div>
    </button>
  );
}

    src/components/ProgressBar.jsx: "Card X of Y" and a fill bar

    export default function ProgressBar({ current, total }) {
  const percent = total ? Math.round((current / total) * 100) : 0;

  return (
    <div className="progress">
      <div className="progress-text">
        Card {current} of {total}
      </div>
      <div
        className="progress-track"
        role="progressbar"
        aria-valuemin={0}
        aria-valuemax={100}
        aria-valuenow={percent}
      >
        <div className="progress-fill" style={{ width: `${percent}%` }} />
      </div>
    </div>
  );
}

    Layers

    LayerWhereResponsibility
    Typessrc/types/Shared shapes, such as Card. No runtime code.
    Datasrc/data/cards.tsPlain data. No React imports, so it's easy to edit or replace.
    Statesrc/hooks/useFlashcards.tsOwns index and flipped, and exposes the values and actions. The only place that holds state.
    Presentationsrc/components/Stateless, reusable components that receive props and call callbacks.
    Stylingsrc/index.cssClass-based styles and CSS variables for light and dark themes.

    Rules to keep it simple

    • Keep state in useFlashcards. Components get values through props and call actions through callbacks.
    • Components take data and callbacks as props. They don't read cards.js directly, except through App.
    • Moving to another card always resets flipped to false. This is handled in goTo.
    • Add a new feature as a new file in src/components/, then import it in App.tsx.

    Data flow

    data/cards.ts ──► useFlashcards (index, flipped, actions)
                        │
                       App
               ├── ProgressBar  (current, total)
               ├── FlashCard    (card, flipped, onFlip)  ──► flip() toggles flipped
               └── Controls     (flipped, isFirst, isLast, onPrevious, onFlip, onNext)

    Part 3: Convert the project to TypeScript

    Do this after Part 2. The JavaScript versions of the files in step 7 are the starting point. Part 3 replaces them.

    T1. Rename the source files

    Use git mv so git tracks the renames:

    git mv src/cards.js src/cards.ts
git mv src/main.jsx src/main.tsx
git mv src/App.jsx src/App.tsx
git mv src/components/FlashCard.jsx src/components/FlashCard.tsx
git mv src/components/ProgressBar.jsx src/components/ProgressBar.tsx
git mv vite.config.js vite.config.ts

    Then change the script in index.html to load the TypeScript entry:

    <script type="module" src="/src/main.tsx"></script>

    T2. Install TypeScript and the React type packages

    npm install -D typescript@5.6.3 @types/react@18.3.12 @types/react-dom@18.3.1

    The versions are pinned to match the rest of package.json.

    T3. Add tsconfig.json

    Create this file in the project root. strict turns on full type checking. noEmit means TypeScript only checks types; Vite does the compiling.

    {
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "jsx": "react-jsx",
    "skipLibCheck": true,
    "isolatedModules": true,
    "noEmit": true,
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "noFallthroughCasesInSwitch": true
  },
  "include": ["src"]
}
