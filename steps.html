Flash Card App: Setup Steps

Recreates this project from an empty folder. Requires Node 18+ and npm.

1. Create the folder and initialize git

mkdir flashCard && cd flashCard
git init

2. Create the files

Create each file with the exact contents from this repo's history. Each file was committed on its own, so use git show <hash>:<path>, for example git show d988b2e:package.json. Or clone this repo and skip to step 3.

3. Install dependencies

npm install

Installs React 18.3.1, Vite 5.4.11 and @vitejs/plugin-react 4.3.4, pinned in package.json.

4. Run the app

npm run dev

Or run ./run.sh, which installs dependencies on first run and then starts the dev server. Open the URL Vite prints, usually http://localhost:5173.

5. Build for production

npm run build

Output goes to dist/. Preview it with npm run preview.

Adding cards

Edit the cards array in src/cards.js. Each entry is { question, answer }.
